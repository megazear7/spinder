# Spinder

[spinder.alexlockhart.me](https://spinder.alexlockhart.me/)

Spinder is a client only web app that allows you to more easily understand your expenses.

## Setup

```sh
nvm use 22
npm install
npm start
```

Open [localhost:3000](http://localhost:3000/)

## Develop

Hot reloading is in place on all files.
Review the prompt instructions under `.github/prompts` for coding guidelines.

```
npm start
```

## Lint & Fix

```
npm run lint
npm run fix
```

## Build

```
npm run build
```

## Deploy

Push to the `main` branch.
